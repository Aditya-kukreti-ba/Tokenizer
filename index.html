What is Tokenization?

Tokenization is the process of splitting text into meaningful units called tokens. These can be words, subwords, sentences, or characters. It's the foundational first step in any NLP pipeline.

📦

word_tokenize()

Uses the Punkt tokenizer trained on English. Handles contractions (don't → do + n't), abbreviations (Dr.), and punctuation intelligently. Equivalent to TreebankWordTokenizer.

📄

sent_tokenize()

Uses NLTK's Punkt sentence tokenizer. Handles tricky cases like "Dr. Smith" vs end-of-sentence periods. Language models are available for 17+ languages.

🔍

RegexpTokenizer

Allows custom tokenization via regular expressions. Can match tokens or gaps. Great for domain-specific text like medical notes, social media, or code.

🧹

Stopword Removal

Stopwords are high-frequency words (the, is, at) that carry little semantic meaning. NLTK provides stopword lists for 23 languages via nltk.corpus.stopwords.

⚡

Quick Start

Install: pip install nltk
Then: import nltk; nltk.download('punkt'); nltk.download('stopwords')
You're ready to tokenize!

// FULL NLTK CHEATSHEET 
import nltk
from nltk.tokenize import word_tokenize, sent_tokenize, RegexpTokenizer
from nltk.corpus import stopwords

# ─── Setup (run once) ───────────────────────────────────────
nltk.download('punkt')
nltk.download('punkt_tab')
nltk.download('stopwords')
nltk.download('averaged_perceptron_tagger')

text = "Dr. Smith's lab isn't open today. Let's try again!"

# ─── Word Tokenization ──────────────────────────────────────
tokens = word_tokenize(text)
# → ['Dr.', 'Smith', "'s", 'lab', "isn't", 'open', ...]

# ─── Sentence Tokenization ──────────────────────────────────
sentences = sent_tokenize(text)
# → ["Dr. Smith's lab isn't open today.", "Let's try again!"]

# ─── RegexpTokenizer ────────────────────────────────────────
tokenizer = RegexpTokenizer(r'\w+')
tokens_re = tokenizer.tokenize(text)
# → ['Dr', 'Smith', 's', 'lab', 'isn', 't', 'open', ...]

# ─── Remove Stopwords ───────────────────────────────────────
stop_words = set(stopwords.words('english'))
filtered = [w for w in tokens if w.lower() not in stop_words]

# ─── POS Tagging (bonus!) ───────────────────────────────────
tagged = nltk.pos_tag(tokens)
# → [('Dr.', 'NNP'), ('Smith', 'NNP'), ("'s", 'POS'), ...]

# ─── Token Frequency ────────────────────────────────────────
from nltk import FreqDist
fdist = FreqDist(tokens)
fdist.most_common(5)  # top 5 tokens
